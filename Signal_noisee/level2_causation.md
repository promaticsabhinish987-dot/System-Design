# Chapter 2: Causation

## Objective

Learn how to distinguish true causes from mere associations.

This chapter is the foundation of critical thinking, debugging, scientific reasoning, investing, engineering, and decision-making.

---

# Core Principle

Not everything that appears together is causing the outcome.

Reality contains:

```text
Observations
      ↓
Correlations
      ↓
True Causes
      ↓
Outcome
```

The goal is to find causes, not associations.

---

# Knowledge Gap

Humans naturally confuse:

```text
Correlation
```

with

```text
Causation
```

This is one of the most common thinking errors.

---

# Definitions

## Correlation

### Definition

A relationship where two variables appear together.

Correlation means:

```text
A changes
and
B changes
```

But it does not prove:

```text
A causes B
```

---

### Example

Good programmers often drink coffee.

Observation:

```text
Coffee
↔
Programming Skill
```

Question:

Does coffee create programming skill?

Answer:

No evidence.

Coffee and programming skill occur together.

This is correlation.

---

## Causation

### Definition

A relationship where one variable directly influences an outcome.

Causation means:

```text
A
↓
Creates Change In
↓
B
```

---

### Example

Programming Practice

```text
Practice
↓
Improved Problem Solving
↓
Better Programming Skill
```

This is causation.

---

# First Principle

A signal must cause the outcome.

If a variable does not influence the outcome, it is not a signal.

---

# Cause vs Correlation

## Correlation

Characteristics:

* Appears together
* May be coincidence
* Does not explain outcome
* Cannot reliably predict change

Example:

```text
Coffee ↔ Good Programmers
```

---

## Cause

Characteristics:

* Produces outcome
* Changes outcome when modified
* Explains mechanism
* Predicts future outcomes

Example:

```text
Practice
↓
Skill Development
```

---

# The Removal Test

## Most Important Tool

Ask:

```text
If I remove this variable,
does the outcome change?
```

If YES:

Possible cause.

If NO:

Likely noise.

---

### Example 1

Outcome:

Pass Coding Interview

Variables:

* DSA Practice
* Keyboard Brand

Remove DSA Practice:

Interview performance drops.

Possible cause.

---

Remove Keyboard Brand:

Interview performance unchanged.

Noise.

---

### Example 2

Outcome:

Weight Loss

Variables:

* Calorie Deficit
* Workout Shoes Color

Remove Calorie Deficit:

Weight loss stops.

Cause.

---

Remove Shoe Color:

No change.

Noise.

---

# Mental Model

```text
Variable
    ↓
Mechanism
    ↓
Outcome
```

Every true cause has a mechanism.

---

# Mechanism

## Definition

The process through which a cause produces an outcome.

---

### Example

Outcome:

Website Slow

Cause:

Database Query

Mechanism:

```text
Database Query
      ↓
Long Execution Time
      ↓
Slow Response
      ↓
Website Slow
```

Without a mechanism, causation is weak.

---

# Three Levels of Confidence

## Level 1

Observation

```text
A and B occur together
```

Weakest evidence.

---

## Level 2

Correlation

```text
A consistently appears with B
```

Stronger evidence.

---

## Level 3

Causation

```text
A directly changes B
```

Strongest evidence.

# Common Mistakes

## Mistake 1

Assuming association means causation.

Example:

```text
Successful people wake up at 5 AM.
```

Question:

Does waking at 5 AM create success?

Not necessarily.

---

## Mistake 2

Ignoring hidden variables.

Example:

```text
Ice cream sales increase.
Drowning incidents increase.
```

Hidden variable:

```text
Summer
```

Summer causes both.

Ice cream does not cause drowning.

---

## Mistake 3

Confusing symptoms with causes.

Example:

Outcome:

Server Failure

Symptom:

High CPU

Question:

What caused high CPU?

Need deeper investigation.

# Signal Extraction Framework

When analyzing any outcome:

Step 1

Define outcome.

---

Step 2

List possible variables.

---

Step 3

Apply removal test.

```text
If removed,
does outcome change?
```

---

Step 4

Find mechanism.

```text
How does this variable
create the outcome?
```

---

Step 5

Separate:

```text
Cause
vs
Correlation
```
